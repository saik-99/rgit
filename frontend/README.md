## 🎯 Role & Project Scope: UrbanIncident Fusion
Your job is to build the operator-facing interface that visualizes how fragmented city signals collapse into a single evolving incident:

### Key Requirements
1. **Live Incident Feed / Map**: Show incoming signals and active clustered incidents.
2. **Causal & Evidence Graph View**: Display the root cause (e.g. Drainage Failure) pointing to observed symptoms (Water Level Spike, Traffic Jam).
3. **Confidence & Uncertainty Indicator**: Visual gauge showing how confidence updates as new evidence arrives.
4. **Operator Briefing Box**: Clean presentation for the natural language summary generated by Person 4's AI agent.
